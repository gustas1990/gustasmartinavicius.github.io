Projects

01

Job Application Automater

AI-assisted recruitment management platform

View on GitHub ↗

A React-based web application designed to make the recruitment process more efficient by bringing candidate applications, information and recruitment progress into one interface.

The project was developed during my BSc (Hons) Computer Science degree at the University of Staffordshire. It combines frontend development, cloud technologies and AI-related functionality with a focus on the practical needs of recruiters.

01 · PURPOSE

The problem

Recruitment teams often have to work through large numbers of applications while keeping track of candidate information and their position within the recruitment process.

I wanted to explore how a centralised application could simplify this process and make candidate information easier to review and manage.

02 · SOLUTION

The application

The application provides a recruiter-focused interface for viewing candidate applications, reviewing relevant information and managing progression through the recruitment process.

The interface was designed around usability, with the aim of making important information accessible without requiring the user to understand the technical system behind it.

03 · ARCHITECTURE

How it works

The application is built using React. The interface is separated into reusable components, with JavaScript handling application behaviour and user interactions.

User ↓ React Interface ↓ Application Logic ↓ AWS / Cloud Services ↓ Application Data
04 · TECHNOLOGY

How it was built

The frontend uses React, JavaScript, HTML and CSS. AWS Amplify is used to support the cloud side of the application.

React JavaScript HTML CSS AWS Amplify Git GitHub Node.js
05 · WHAT I LEARNED

Technical and practical experience

The project gave me practical experience with React, application structure, JavaScript, cloud services, debugging and Git. More importantly, it required me to think about the relationship between the technology and the people using it.

Building the application from a recruiter's perspective meant considering how information should be presented, how users move through the system and how a technical solution should support a business process.

06 · RELEVANCE

Why this project matters to my direction

This project reflects the type of work I am interested in pursuing. My background is technical, but I am particularly interested in technology consulting, cloud consulting and client-facing technical roles rather than focusing solely on software development.

The project required both technical understanding and consideration of the people and business process behind the system. That combination is a strong reflection of the direction I want to take professionally.
